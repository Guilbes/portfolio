# Computer Health Report

## Goal
Inspect my laptop like an IT technician and recommend improvements.

## Tools Used
- Task Manager
- Device Manager
- Windows Settings

## What I Did
1. Checked system specs (CPU, RAM, Windows version)
2. Reviewed performance in Task Manager
3. Checked Device Manager for driver problems
4. Ran Windows Update

## Results & Recommendations
- while scanning the device manager I found a warning icon on a device which I later found out
  was from my USB input device.
- while inspecting the task manager and the specs I found out that this device does not support
  windows 11 and recommend upgrading for file and security safety due to the device not being
  updated to the latest model.
- This device has good storage device but one recommendation I have is to delete the 33 gb of
  temp storage.
- This device does not support the latest version of windows 11.

## What I Learned
- One of the things that I have learned while doing this project is that simply inspecting the
  device manager and the drivers you could figure out the hardware and software problems easily and promptly fix them.
